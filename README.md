# FASTLANES – Website

Code der Website fastlanes.de. Statische Mehrseiten-Website (ursprünglich Webflow), gebaut mit Vite.

```bash
npm install
npm run dev      # Vorschau auf http://localhost:8080
npm run build    # fertige Website in dist/
```

Eigene Style-Änderungen gehören in `public/css/custom.css`. Details für Entwickler/KI: siehe [CLAUDE.md](CLAUDE.md).
